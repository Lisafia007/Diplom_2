**Задание 2. Автотесты для API**

Автотесты для проверки эндпоинов API для Stellar Burgers(https://stellarburgers.education-services.ru/)

Реализованные проверки:
• Создание пользователя: регистрация уникального пользователя; запрет повторной регистрации; валидация при незаполненных обязательных полях.
• Логин пользователя: вход под существующим пользователем; обработка ошибки при неверном логине/пароле.
• Создание заказа: с авторизацией и без; с ингредиентами, без ингредиентов, а также с неверным хешем ингредиентов.

Структура проекта:
• Директория tests/: содержит тест-кейсы, разделенные по логическим модулям (test_user_creation.py, test_user_login.py, test_order_creation.py). Все тесты детализированы шагами allure.step.
• Директория data/: отвечает за конфигурацию окружения. Включает базовые адреса (urls.py) и эндпоинты (endpoints.py).
• Файл conftest.py: хранит глобальные фикстуры Pytest для подготовки тестовой среды (авторизация, получение ингредиентов) и автоматической очистки данных (удаление пользователей после тестов).
• Файл helpers.py: содержит утилитарные методы для динамической генерации уникальных тестовых данных (email, пароли, имена).
